---

## Estructura del Proyecto
* `models/`: Clases de entidad puras.
* `db/`: Conexión a SQLite y tablas base.
* `repositories/`: Persistencia e interacciones SQL.
* `services/`: Reglas de negocio y validaciones.
* `ui/`: Interfaz Tkinter / ttk.

---

## Ejecución
Instala las dependencias con `pip install -r requirements.txt` y ejecuta `python main.py`.
